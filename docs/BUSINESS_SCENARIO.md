# 业务场景定位：面向高校计算机专业学生的「课程学习研究助手」

> 2026-08-22 定稿。目的：把 deep-research-agent + CourseRAG 从"通用研究工具"重新定位为
> **有明确用户、明确需求、真实数据、效果可评估**的垂直场景 Agent，消除"为 agent 而 agent"质疑。

---

## 1. 场景一句话

**给高校计算机专业学生(以本人为原型)用的课程学习研究助手**:课程知识点问答 + 深度调研 + 本地部署,数据不出机器。

## 2. 用户与需求(真实,不编)

| 维度 | 内容 |
|---|---|
| 目标用户 | 高校计算机专业学生(本人为 0 号用户:嘉应学院计算机科学与技术专业) |
| 真实痛点 | ① 期末复习:知识点散落在多门课笔记/教材里,检索靠 Ctrl+F;② 课程答疑:问 AI 泛化模型(通用知识)不如查自己的课程笔记准;③ 作业/调研:写课程报告需要多来源交叉验证;④ 隐私:课程笔记含个人信息,不想上传云端 AI |
| 用户故事 | 复习《数据库》时问"ACID 特性靠什么机制实现?"→ 助手从自己的课程笔记+教材定位原文(而非泛化回答);调研"Redis 与 MySQL 的缓存一致性"→ 深度研究 Agent 多步搜索输出带来源报告 |
| 为什么是"真需求" | 本人(目标用户)在期末复习/作业中实际使用;需求来自个人真实学习场景,非虚构访谈 |

## 3. 产品形态(两个项目如何组合)

```
┌─────────────────────────────────────────────────┐
│  课程学习研究助手                                 │
│                                                   │
│  CourseRAG(知识底座)   ←HTTP解耦→   deep-research │
│  · 课程笔记+教材 993 块        · Agent(研究能力)   │
│  · 混合检索+重排              · 三节点编排          │
│  · 快速问答/引用溯源          · 多步搜索/带来源报告  │
│  · 本地 Ollama 生成           · course_retrieve 工具 │
│                             · 本地/云模型可选      │
└─────────────────────────────────────────────────┘
```

- **CourseRAG 答"这个知识点是什么"**(单轮、快、带引用)
- **deep-research 答"这个问题需要多步调研"**(研究报告、带来源)
- 两套互补:知识检索 + 研究编排,组合成一个完整的学习助手

## 4. 与市面上教育 AI 的差异化(面试必问)

| 对比项 | 作业帮/AI 助教等 | 本项目 |
|---|---|---|
| 知识来源 | 通用大模型知识 | **用户自己的课程笔记+教材**(垂直,答的是"你们课上讲的那个版本") |
| 引用溯源 | 弱/无 | **每个事实带来源标注 [n]**(可回原文核对) |
| 调研能力 | 单轮问答 | **多步深度研究**(规划→执行→反思→报告) |
| 部署 | 云端(数据出境) | **本地部署可选**(数据不出机器) |
| 成本 | 订阅费 | **本地 Ollama 免费 / API 极低(约 6 元/16 条)** |

**一句话差异**:不是"又一个 AI 问答",而是"**用你自己的课程资料,答你自己课程的问题,还能做深度调研**"。

## 5. 效果评估(现状 + 待补)

### 已有(硬数据)
- CourseRAG:100 题 × 697 块评估,混合检索 vs 纯向量四项全正向(precision +0.18 / recall +0.16);993 块语料待重测
- deep-research:17 条评测集,规划 100% / 完成 100% / 命中 94%(单次);反思对照实验(#1 早停 0.67→1.0, #3 省 83% token)
- 集成对比:web+RAG 较纯 web 耗时 -18%、token -4%,命中持平(评测题选的通用知识,如实)

### 待补(教育场景专属评估)
1. **课程题命中率**:在 993 块新语料上重跑 100 题评估(跨语料基线需重测)
2. **真实用户反馈**:找 2-3 名同学试用,收集"答案是否可用/引用是否可追溯"的定性反馈(不做假数据)
3. **拒答正确率**:语料外问题(如"今天天气")应触发 low_confidence,评估拒答率

## 6. 叙事模板(简历/面试 30 秒版)

> 「我做了个面向高校计算机学生的课程学习研究助手:**CourseRAG** 用学生自己的课程笔记+教材(993 块)做垂直问答,自研混合检索(向量+BM25+RRF)答课程题带来源引用;**deep-research Agent** 做多步深度调研,三节点编排(规划-执行-反思),输出带来源报告;两个通过 course_retrieve 工具解耦集成。评估:100 题四项指标全正向、17 条评测集命中 94%、集成后检索效率提升 18%,全本地部署保护隐私。」

## 7. 边界(主动承认)

- 用户目前主要是"本人自用",同学试用反馈是下一步(不能伪造);
- 课程题评估与语料同源,绝对值偏乐观,看 A/B 差值与方向;
- 教育行业竞争激烈,差异化靠"垂直课程资料 + 引用溯源 + 本地部署"组合,单点不强。
